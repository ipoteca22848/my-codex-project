# Celebression + Angel Visuals

Готовый мод: `celebression-1.0.0-angel-visuals.jar`.

Minecraft 1.21.11, Java 21, Fabric Loader >=0.19.5, Fabric API >=0.141.6+1.21.11 для Minecraft 1.21.11.

Установите JAR вместо предыдущего Celebression. Отдельный AngelVisuals не требуется.

36 визуальных модулей находятся в Right Shift → Render с префиксом AV /. Дополнительные настройки — Advanced settings. Главное меню сохранено; HUD донора не подключён.

Проверены включение 36 модулей в локальном мире, переключатель в меню Celebression, расширенные настройки, шейдер стекла, клавиша создания метки, клиентское время суток, сохранение настроек и совместная отрисовка косметики. Все стили, события боя и сочетания сторонних модов не проверялись.
