# Celebression 1.0.2 — Angel Visuals + HitSwap

Скачать: `celebression-1.0.2-angel-visuals-hitswap.jar` (Download raw file на странице файла).

Minecraft 1.21.11, Java 21, Fabric Loader >=0.19.5, Fabric API >=0.141.6+1.21.11 для Minecraft 1.21.11.

Замените предыдущий Celebression этим JAR. Отдельные AngelVisuals и HitSwap устанавливать не нужно.

## Что исправлено

- Оставлено одно новое главное меню; классы старых главных экранов удалены. Аккаунты открываются отдельно и возвращают в новое меню. Внизу главного меню: Celebression 1.0.2 | Visuals: 37.
- Добавленные функции видны первыми в Right Shift → Render. HitSwap — первая карточка AV / HitSwap. Основные параметры находятся в карточках, цвета и текстуры — в Advanced settings.
- HitSwap визуально переключает руки после каждого удара или только критического удара. Предметы в инвентаре не переставляются; отключение восстанавливает исходный вид.
- Исправление совместимости с Sodium/Iris сохранено: с Sodium отключён только Chunk Fade. Новый HUD не добавлен, существующий HUD Celebression сохранён.

## Проверки

Готовый производственный JAR запущен обычным Fabric без dev-классов. Проверены 37 функций без Sodium; с Sodium 0.8.4 и Iris 1.10.5 — 36, Chunk Fade отмечен как неподдерживаемый. Проверены первое место новых карточек в Render, единственное главное меню и аккаунты, HitSwap на обычных и падающих критических атаках, отсутствие перемещения предметов, восстановление рук при отключении, сохранение настроек и совместный рендер косметики. Все стили и весь сторонний набор модов пользователя не проверялись.
